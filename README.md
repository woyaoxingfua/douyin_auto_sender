# 抖音PC客户端 - 每日天气助手-自动续火花 (OCR增强版)

本项目是一个经过重构和优化的 Python 桌面UI自动化工具，旨在每日定时向指定的抖音好友发送其所在城市的天气预报。通过结合和风天气API、RapidOCR本地文字识别（基于PaddleOCR）、图形用户界面(GUI)配置工具以及 PyAutoGUI 库，实现高度自动化、稳定可靠的每日任务。

相较于旧版，v5.0 新增了**本地OCR文字识别**支持，无需网络即可使用，且支持文字边界提取，定位更精准。

## ✨ 主要功能

*   **三重识别模式**：
    *   **PaddleOCR本地识别**（推荐）：使用开源PaddleOCR引擎，完全离线运行，支持文字检测和边界提取，定位更精准。
    *   **百度OCR识别**（备选）：当PaddleOCR不可用时，自动切换到百度OCR在线服务。
    *   **传统图像识别模式**：保留原有PyAutoGUI图像识别方式，适合习惯使用截图的用户。
*   **双重运行模式**：
    *   **定时调度模式**：默认模式，启动一次主程序 (`douyin_bot.py`)，即可实现每天早上 8:00 自动执行，无需人工干预。
    *   **立即执行模式**：通过命令行参数 `--now`，可让任务立即执行一次，方便测试和按需运行。
*   **高度可配置与个性化**：
    *   **图形化配置后台** (`config_manager_gui.py`)：提供用户友好的GUI界面，轻松管理API、好友和城市信息。
    *   **自定义消息模板**：在GUI中自由编辑天气播报文案，支持多种变量，让您的问候与众不同。
*   **健壮性与稳定性增强**：
    *   **专业日志系统**：用 `logging` 模块取代了简单的 `print`，所有操作和潜在错误都会记录到 `run.log` 文件中，便于追溯和调试。
    *   **日志滚动**：`run.log` 自动轮转，避免长期运行导致日志文件无限增大。
    *   **网络重试机制**：为天气API请求增加了 `tenacity` 库支持的重试功能，有效应对瞬时网络波动。
    *   **区域化图像识别**：限定 `pyautogui` 在屏幕的特定区域（如右侧列表、右下角聊天区）寻找图像，大幅提升识别速度和准确性。
*   **更佳的用户体验与安全性**：
    *   **API连通性测试**：在GUI中一键测试和风天气API Key的有效性。
    *   **敏感数据保护**：支持从环境变量读取API密钥，避免在配置文件中明文存储，更加安全。

## ️ 环境安装与配置

#### 1\. 软件依赖

*   **Python**: 建议使用 3.8 或更高版本。

#### 2\. Python库安装

项目依赖已全部记录在 `requirements.txt` 中。请在项目根目录打开终端，运行以下命令以安装所有必需的Python库：

```bash
pip install -r requirements.txt
```

这会安装 `pyautogui`, `requests`, `opencv-python`, `pyperclip`, `tenacity`, `schedule`, `pillow`, `rapidocr_onnxruntime` 等所有必要的库。

#### 3\. 本地OCR配置 (推荐)

RapidOCR是基于PaddleOCR的轻量级封装，完全离线运行，无需API Key。

1.  首次运行时，RapidOCR会自动下载模型文件（约10MB，比PaddleOCR小很多）。
2.  在配置界面的"OCR配置"标签页中，确保"启用本地OCR识别"已勾选（默认已启用）。

#### 4\. 百度OCR配置 (可选)

当本地OCR不可用时，系统会自动切换到百度OCR在线服务。

1.  访问 [百度AI开放平台](https://ai.baidu.com/tech/ocr) 并注册账号。
2.  在控制台创建一个应用，选择"文字识别"服务。
3.  获取 `API Key` 和 `Secret Key`。
4.  在配置界面的"OCR配置"标签页中填入上述信息。
5.  每月有2000次免费调用额度，足够日常使用。

#### 5\. 可选：运行快速自检

```bash
python -m py_compile *.py
pytest -q
```

## 📖 使用指南

#### **第一步：配置 (仅需一次或在需要修改时运行)**

1.  **运行配置工具**: 首次使用或需要修改配置时，请运行 `config_manager_gui.py` 文件。
    ```bash
    python config_manager_gui.py
    ```
2.  **填写天气API信息**:
    *   在 "天气API" 标签页中，填入您从 **和风天气开发者平台** 获取的 `API Host` 和 `API Key`。
    *   点击 **"测试连接"** 按钮，确保您的API配置无误。
3.  **自定义消息模板 (可选)**:
    *   在 "消息模板配置" 区域，您可以修改天气播报的文案。其中 `{nickname}`、`{city_name}` 等变量会在发送时被自动替换。
4.  **配置OCR (推荐)**:
    *   切换到 "OCR配置" 标签页。
    *   **本地OCR配置（推荐）**：
        *   确保"启用本地OCR识别"已勾选（默认已启用）。
    *   **百度OCR配置（可选）**：
        *   当本地OCR不可用时，系统会自动使用百度OCR。
        *   填入百度OCR的 `API Key` 和 `Secret Key`。
5.  **添加与管理好友**:
    *   切换到 "好友管理" 标签页。
    *   使用 "查找城市ID" 功能找到好友所在城市的ID。
    *   填写好友昵称。
    *   选择识别方式：
        *   **OCR文字识别模式（推荐）**：输入好友在抖音私信列表中显示的文字（通常是好友昵称）。
        *   **图像识别模式**：关联该好友的头像截图（需提前截好并放入 `friend_avatars` 文件夹）。
    *   点击 **"添加为新好友"** 或 **"更新选中好友"**。
6.  **保存配置**: 完成所有操作后，点击 **"️ 保存所有配置并退出"**。程序会自动生成或更新 `config.json` 文件。

#### **第二步：启动自动化机器人 (选择一种模式)**

**模式一：定时调度 (长期运行)**
此模式适用于将程序部署在服务器或个人电脑上长期自动运行。

1.  **运行主程序**: 在终端中直接运行 `douyin_bot.py`。
    ```bash
    python douyin_bot.py
    ```
2.  **程序将进入后台等待**：启动后，程序会显示 "任务已调度：每天08:00执行抖音天气助手。" 的日志，然后保持运行，等待预设时间的到来。**您可以最小化此终端窗口，但不要关闭它**。

**模式二：立即执行 (用于测试或按需运行)**
此模式适用于立即测试或手动执行一次任务。

1.  **使用 `--now` 参数运行**: 在终端中运行 `douyin_bot.py` 并附带 `--now` 参数。
    ```bash
    python douyin_bot.py --now
    ```
2.  **程序将立即执行任务**：启动后，程序会显示 "接收到 --now 参数，任务将立即执行..." 的日志，然后开始执行一次完整的自动化流程。任务结束后，程序会自动退出。

## 🔒 安全建议：使用环境变量 (推荐)

为了避免 API Key 泄露，建议您使用环境变量来存储它，而不是保存在 `config.json` 中。

1.  **设置环境变量**:
    *   **Windows**: 
        ```cmd
        set DOUYIN_WEATHER_API_KEY=你的天气APIKey
        set BAIDU_OCR_API_KEY=你的OCR-APIKey
        set BAIDU_OCR_SECRET_KEY=你的OCR-SecretKey
        ```
    *   **macOS/Linux**: 
        ```bash
        export DOUYIN_WEATHER_API_KEY="你的天气APIKey"
        export BAIDU_OCR_API_KEY="你的OCR-APIKey"
        export BAIDU_OCR_SECRET_KEY="你的OCR-SecretKey"
        ```
2.  **程序将自动优先使用**：如果检测到对应的环境变量，程序会优先使用它们，并忽略配置文件中的相应字段。

## ️ 注意事项

*   **本地OCR优势**：使用RapidOCR本地识别，完全离线运行，无需网络，且支持文字边界提取，定位更精准。
*   **截图精度**（图像识别模式）：程序的识别成功率与您的截图精度直接相关。如果某个按钮找不到，请尝试重新截取。
*   **界面更新**：如果抖音PC客户端版本更新导致UI文字发生变化，您可能需要更新好友的OCR文字配置。
*   **紧急停止**：程序内置了 `pyautogui.FAILSAFE` 机制。在自动化任务执行期间，如果您想紧急停止，只需将鼠标指针**猛地移动到屏幕的左上角**即可。
*   **日志查看**：如果程序运行异常，请打开项目根目录下的 `run.log` 文件，查看详细的错误信息。

## 🔧 OCR识别模式详解

### 工作原理

OCR识别模式通过本地RapidOCR引擎识别屏幕上的文字来定位按钮，而不是通过图像匹配。

1.  **截图**：程序会截取当前屏幕的指定区域。
2.  **文字检测**：RapidOCR检测图像中的文字区域，返回边界框（bounding box）。
3.  **文字识别**：对检测到的文字区域进行OCR识别，获取文字内容。
4.  **文字匹配**：在识别结果中查找目标文字（如"私信"、"发送"等）。
5.  **精准定位**：根据边界框计算文字中心点，实现精准点击。

### 优势

*   **完全离线**：无需网络，无需API Key，完全本地运行。
*   **边界提取**：RapidOCR支持返回文字的边界框，可以实现更精准的定位。
*   **适应性强**：即使按钮位置发生变化，只要文字不变就能正常工作。
*   **免费开源**：RapidOCR基于PaddleOCR，是开源项目，无任何费用。
*   **轻量快速**：模型仅约10MB，启动快，识别速度快。

### 本地OCR vs 百度OCR

| 特性 | 本地OCR (RapidOCR) | 百度OCR |
|------|-----------|---------|
| 网络要求 | 无需网络 | 需要网络 |
| 费用 | 免费 | 每月2000次免费 |
| 边界提取 | 支持 | 支持 |
| 识别精度 | 高 | 高 |
| 首次使用 | 需下载模型(10MB) | 无需下载 |

## ❓ 常见问题

### Q: OCR模式和图像识别模式有什么区别？

**A:** 
- **OCR模式**：通过识别界面上的文字来定位按钮，无需截取控制图像，适应性更强。
- **图像识别模式**：通过图像匹配来定位按钮，需要提前截取控制图像，对界面变化更敏感。

### Q: 如何选择识别模式？

**A:** 
推荐使用OCR模式（特别是本地OCR），除非：
- 您的界面有无法通过文字识别的元素（如纯图标按钮）
- 本地OCR安装失败（此时可使用百度OCR或图像识别模式）

### Q: 本地OCR识别失败怎么办？

**A:** 
1. 确认已安装RapidOCR：`pip install rapidocr_onnxruntime`
2. 查看日志文件 `run.log` 获取详细错误信息
3. 如果本地OCR不可用，系统会自动尝试使用百度OCR
4. 如果百度OCR也不可用，会回退到图像识别模式

### Q: 首次运行本地OCR很慢？

**A:** 
首次运行时，RapidOCR会自动下载模型文件（约10MB），之后会缓存到本地，后续运行会很快。

### Q: 如何获取好友在私信列表中的显示文字？

**A:** 
打开抖音PC客户端的私信列表，观察好友在列表中的显示方式。通常是好友的昵称或备注名。
